# Train Pipeline Design

**Date:** 2026-05-28
**Status:** Approved

## Overview

A thin CLI wrapper (`rehearse-train`) around moshi-finetune's `torchrun`-based training script. Uses `chz` for configuration management, consistent with `annotate.py` and `dataset.py`. Accepts a base training YAML plus key override flags; merges them and delegates to torchrun.

## Module Structure

```
rehearse/train/
├── __init__.py                   (empty)
└── cli.py                        (new)

rehearse/models/
└── moshi_7B/
    └── config.yaml               (base training config, committed to repo)
```

`rehearse-train` is registered as an entry point in `pyproject.toml`, matching the pattern of `rehearse-eval`.

## TrainConfig (chz)

```python
@chz.chz
class TrainConfig:
    config: Path = Path("rehearse/models/moshi_7B/config.yaml")
    """Base training YAML. Defines data paths, LoRA settings, optimizer params.
    Defaults to the bundled moshi-7B config."""

    run_dir: str = ""
    """Output directory for checkpoints and logs.
    Defaults to runs/<config-stem>-<YYYYMMDD-HHMMSS> if empty."""

    gpus: int = 1
    """Number of GPUs passed to torchrun --nproc-per-node. Use 1 for a single GPU."""

    max_steps: int = 0
    """Training steps. 0 = use value from YAML (default 2000).
    Total tokens ≈ max_steps × gpus × batch_size × duration_sec × 9 × 12.5."""

    batch_size: int = 0
    """Examples per GPU per step. 0 = use value from YAML (default 16).
    Reduce if you hit OOM; also try lowering duration_sec."""

    lora_rank: int = 0
    """LoRA adapter rank. 0 = use YAML value (default 128). Keep ≤ 128."""

    duration_sec: float = 0.0
    """Max sequence length in seconds. 0 = use YAML value (default 100).
    Lowering reduces memory but may degrade quality."""

    dry_run: bool = False
    """Print the resolved torchrun command without executing."""
```

Zero/empty values mean "don't override" — the base YAML value is used as-is.

## Merge Logic

`_merge_yaml(config: TrainConfig) -> Path`:

1. Load base YAML with `yaml.safe_load`
2. If `run_dir` is empty, generate `runs/<config-stem>-<YYYYMMDD-HHMMSS>` and set it
3. Apply non-zero overrides using this field → YAML key mapping:

```python
OVERRIDES = {
    "run_dir":      ("run_dir",),
    "max_steps":    ("max_steps",),
    "batch_size":   ("batch_size",),
    "duration_sec": ("duration_sec",),
    "lora_rank":    ("lora", "rank"),
}
```

4. Inject `WANDB_API_KEY` from environment into `wandb.key` if present and `wandb` section exists in YAML
5. Write merged dict to `NamedTemporaryFile(suffix=".yaml", delete=False)`
6. Return temp file path

moshi-finetune's `train.py` writes its own `args.yaml` into run_dir after training starts — that is the reproducibility artifact.

## torchrun Invocation

```python
train_py = Path(__file__).parents[2] / "lib" / "moshi-finetune" / "train.py"
cmd = ["torchrun", "--nproc-per-node", str(config.gpus), str(train_py), str(temp_yaml)]
```

`dry_run=True` prints `cmd` and exits. Otherwise `subprocess.run(cmd, check=True)`.

## Entry Point

`pyproject.toml`:
```toml
rehearse-train = "rehearse.train.cli:main"
```

`main()` calls `chz.nested_entrypoint(_run)`.

## Base Config (`rehearse/models/moshi_7B/config.yaml`)

Adapted from `lib/moshi-finetune/example/moshi_7B.yaml` with:
- `data.train_data` and `data.eval_data` left as empty strings (fill at runtime)
- `run_dir` left as empty string (generated by CLI if not overridden)
- `wandb` section omitted (key injected from env var)

## Secrets

`WANDB_API_KEY` is read from the environment at runtime and injected into the merged YAML. It is never stored in a committed file.

## Usage

```sh
# Default moshi-7B config, auto-generated run_dir
rehearse-train

# Override key params
rehearse-train run_dir=runs/my-run max_steps=500 batch_size=8 gpus=4

# Custom base config
rehearse-train config=rehearse/models/moshi_7B/config.yaml run_dir=runs/exp1

# Dry run — print command without executing
rehearse-train dry_run=true
```

## Out of Scope

- Multi-stage pipeline orchestration (annotate → manifest → train) — future work
- Inference / serving the fine-tuned model
- Distributed training across nodes (multi-node torchrun)
